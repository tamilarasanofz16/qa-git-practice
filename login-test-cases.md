# Login Test Cases

## TC001 - Valid Login
1. Open login page
2. Enter valid username
3. Enter valid password
4. Click Login
5. Verify user is logged in

Expected Result:
User should be successfully logged in.

## TC002 - Invalid Password
1. Open login page
2. Enter valid username
3. Enter invalid password
4. Click Login

Expected Result:
Error message should be displayed.
